# Sodalite Swap

Full-colour Python 3 neon match-3 arcade for ElbowOS.

Swap adjacent neon gems to line up 3 or more of the same colour. Matches clear, gems fall, score rises.

## Play

```bash
pip install -r requirements.txt
python3 sodalite_swap.py --play
```

Mouse click adjacent gems to swap. Escape to quit.

## Record a 9:16 reel

```bash
python3 sodalite_swap.py --record
```

Outputs `SODALITE_SWAP_ElbowOS.mp4` (1080x1920, 15s, 30fps).
